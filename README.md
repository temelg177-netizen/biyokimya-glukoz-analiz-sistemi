# Biyokimya Laboratuvarı – Akıllı Glukoz Takip Sistemi

Python kullanılarak geliştirilen bu proje, biyokimya laboratuvarından gelen glukoz sonuçlarını analiz eder ve hastaları glukoz değerlerine göre sınıflandırır.

## Projenin Amacı

Laboratuvar sonuçlarının Python ile otomatik olarak değerlendirilmesini ve kritik değerlerin kolayca belirlenmesini amaçlar.

## Kullanılan Teknolojiler

- Python
- Listeler ve sözlükler
- Döngüler
- Koşullu ifadeler
- Fonksiyonlar

## Proje İçeriği

- Hasta glukoz verilerinin işlenmesi
- Glukoz değerlerinin sınıflandırılması
- Kritik sonuçların belirlenmesi
- Sonuçların raporlanması

## Hedef

Kimya ve biyokimya laboratuvarlarında veri analizinin Python kullanılarak otomatikleştirilmesine yönelik temel bir uygulama geliştirmek.
